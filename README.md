# Network Architect
-> https://gerderverfer.github.io/The-game-about-routers/ <-
Браузерный прототип игры-симулятора сетевой инфраструктуры и кибербезопасности. 

❗️Проект находится в активной стадии разработки. 

Игрок строит сеть из роутеров и серверов, настраивает фаерволы и следит за тем, чтобы пакеты доходили до адресатов, а бюджет не уходил в минус.

### Стек
- **Язык:** TypeScript
- **Движок:** PixiJS (WebGL)
- **Сборщик:** Vite
- **UI:** HTML5 / CSS3 (нативный)
- **Деплой:** GitHub Actions + GitHub Pages
### Управление
- ЛКМ — выделение и перетаскивание нод, панорамирование камеры.
- ПКМ — удаление ноды или связи.
- Колесо мыши — зум.
- Клавиши 1 и 2 — переключение между режимами Pan и Connect.
- Панель слева — каталог оборудования (можно купить).
- Панель справа — инспектор (настройка, включение/выключение нод).

### Как запустить локально
```bash
git clone https://github.com/GerDerVerFer/The-game-about-routers.git
cd The-game-about-routers
npm install
npm run dev
```
